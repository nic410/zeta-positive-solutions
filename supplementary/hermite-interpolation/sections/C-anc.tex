\section{Ancillary files}\label{app:anc}
%======================================================================

The ancillary files of this paper contain, for every computer-assisted statement, the exact input, a standalone verifier
and the log of a fresh run. Their file \nolinkurl{README.md} describes each script in detail; this appendix is an index.
Paths are relative to the top directory of the ancillary files.

\emph{Requirements.} Python $\ge3.10$ with python-flint $0.9.0$ (FLINT $3.6.0$, which contains Arb) and mpmath $1.3.0$;
nothing else. All commands are run from the top directory of the ancillary files, with \texttt{PY} set to such an
interpreter. The wrapper \texttt{runlog.sh LOG "\$PY" SCRIPT ARGS} writes a log whose header records the command, the date
and the software versions, and whose footer records the exit code and the wall time. A run succeeds if it exits with
code $0$ and its final output line reports success (\texttt{CERTIFIED: True}, \texttt{ALL CERTIFIED: \dots} or
\texttt{ALL CHECKS PASSED}; the exact line for each script is listed in \nolinkurl{README.md}). Every script prints the
SHA-256 of each input file; all hashes are listed in \texttt{SHA256SUMS}. The ancillary files are self-contained: they
include a copy of the shared library of \cite{PaperI} (\nolinkurl{lib/}) and copies of the certified enclosures
\nolinkurl{exact/out/P}$J$\nolinkurl{_ball.txt} ($J=10,60,61,110,111$) of the exact members, which the certificates of
Propositions~\ref{prop:roots}, \ref{prop:base} and~\ref{prop:increments} read; these enclosures are produced by the verifier of
Fact~\ref{thm:finiteJ} in the ancillary files of \cite{PaperI}, and the copies are byte-identical. The ancillary files are licensed under the Apache License 2.0 (copyright 2026 Nic Johns); the text is licensed under
CC BY 4.0.

\emph{Re-running.} The script \nolinkurl{toy/run_all.sh} repeats all certificates of the model (about $80$ CPU-minutes) and
\nolinkurl{exact/run_all.sh} those of Section~\ref{ssec:front}, after which \texttt{sha256sum -c SHA256SUMS} checks that inputs
and shipped outputs are unchanged. A single certificate is repeated with the command recorded in the first line of its log,
for example
\begin{verbatim}
./runlog.sh toy/pp80/logs/pp80_tau_K0-134.log "$PY" \
    toy/pp80/verify_pp80_tau.py toy/pp80/params/pp80.json 0 134
\end{verbatim}
The precision, Taylor orders and number of worker processes affect only the running time and the width of the
enclosures, not the validity of a successful run. Computed but uncertified data used in numerical observations are
listed separately in \nolinkurl{README.md}; no statement of this paper depends on them.
