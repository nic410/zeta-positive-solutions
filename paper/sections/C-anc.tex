\section{Ancillary files}\label{app:anc}
%======================================================================

The ancillary files contain, for every computer-assisted statement, the exact input, a standalone verifier and the
log of a fresh run. Their file \nolinkurl{README.md} describes each script in detail; this appendix is an index
(Table~\ref{tab:anc-index}), with the hashes of the headline inputs in Table~\ref{tab:anc-hashes}.

\emph{Requirements.} Python $\ge3.10$ with python-flint $0.9.0$ (FLINT $3.6.0$, which contains Arb) and mpmath $1.3.0$;
nothing else. All commands are run from the top directory of the ancillary files, with \texttt{PY} set to such an
interpreter. The wrapper \texttt{runlog.sh LOG "\$PY" SCRIPT ARGS} writes a log whose header records the command, the date
and the software versions, and whose footer records the exit code and the wall time. A run succeeds if it exits with
code $0$ and its final output line reports success (the exact line for each script is listed in \nolinkurl{README.md}).
The ancillary files are licensed under the Apache License 2.0 (copyright 2026 Nic Johns); the paper itself is licensed under
CC BY 4.0.

\emph{Details of the headline runs.} Theorem~\ref{thm:kappa} with $J=111$ reads \nolinkurl{exact/out/P111_ball.txt} at $3000$ bits, with Taylor
order $28$ ($64$ for $x\ge121$), $x_0=4793/10$ and $6448$ pieces ($6454$ with \texttt{--xmin 1}). Its decisive output lines are
\texttt{A(F\_J) in [3.98510732131e-1060, 3.98510732132e-1060]}, \texttt{kappa* <= 1.4291572e-1060} and, for Corollary~\ref{cor:nearrigid},
\texttt{A(F\_J) <= 3.9851074e-1060}. With \texttt{--xmin 1} the run prints the line \texttt{W\_J: Fhat\_J >= 0 on [x = 1, oo), with exact double
zeros at the 111 nodes and Fhat\_J > 0 elsewhere: True}. All twenty runs of \nolinkurl{cone/} end with \texttt{CERTIFIED: True}, and
\nolinkurl{cone/compare_runs.py} prints \texttt{ALL CONSISTENT} for both ranges. Proposition~\ref{thm:kappaOPS} uses one Arb
integral on $[0,220]$ at $512$ bits and prints \texttt{kappa*\_OPS (and kappa*) of the data <= 9.9461827001452550725e-41}; the run for
Proposition~\ref{prop:lowheight} prints the bound $7.7252542459488902828\cdot10^{-25}$ for $\Arch(F_{80})/\int F_{80}$, and the enclosures of
$\Arch(F_{80})$ and $\int F_{80}$ in its log imply the two bounds stated there. The exact members use $800$ bits ($J=10$), $1800$ ($60$), $2000$ ($61$)
and $3000$ ($110$, $111$); the maximal relative radii of the enclosures are of order $10^{-222}$, $10^{-474}$, $10^{-534}$, $10^{-789}$ and
$10^{-788}$. The pair for Proposition~\ref{prop:lowerbound} uses $8437$ mean-value steps on $[0,2000]$ and prints \texttt{MU FLOOR : mu(t) >= 0.000471949 for
all real t}; the pairs for Proposition~\ref{thm:notcritical} use $17\,214$ and $9501$ steps on $[0,800]$, and the combinations print
\texttt{1.6420748e-5 <= kappa*(Q(sqrt 5)) <= 0.00048294147} and \texttt{0.00015006672 <= kappa*(Q(sqrt -3)) <= 0.00099854968}. The pairs also
print \texttt{supp nu\textasciitilde{} in [x0, oo) with x0 >= 4.049150} (resp.\ \texttt{3.011664}); run with \texttt{--gap-x 4} (resp.\ \texttt{3}),
they print \texttt{admissible at gap xi\_4 (prime measure on [4, oo)): True} (resp.\ \texttt{xi\_3}), and the combinations print that the
bracket and the slack interval hold at the natural gap $\xin4$ (resp.\ $\xin3$). The consistency
check of Lemma~\ref{lem:herglotz} compares both sides of the explicit formula for the three pairs; its residuals are at most $3.2\cdot10^{-30}$, and
it is not used in any proof.

\emph{Re-running.} Each directory has a script \nolinkurl{run_all.sh} that repeats its certificates ($41.6$, $52.0$, $29.1$ and $205.6$
CPU-minutes for \nolinkurl{kappa/}, \nolinkurl{exact/}, \nolinkurl{general/} and \nolinkurl{cone/}: the wall times in the log footers times the
number of workers), after which \texttt{sha256sum -c SHA256SUMS}
checks that inputs and shipped outputs are unchanged. A single certificate is repeated with the command recorded in the first
line of its log, for example
\begin{verbatim}
./runlog.sh cone/logs/W_J111_x2.log "$PY" cone/cert_exact.py 111 \
    --pball exact/out/P111_ball.txt \
    --sha 25669a321f71ddef789247cd0adc0fd129c5d70f293e488bc4dab8c3f708b3f1 \
    --prec 3000 --order 28 --order-far 64 --order-switch 121 \
    --workers 3 --xmin 2 --cost 800 --json cone/out/W_J111_x2.json
\end{verbatim}
The precision, Taylor orders and number of worker processes affect only the running time and the width of the
enclosures, not the validity of a successful run. The floating-point table \nolinkurl{computed/family_J1_110.tsv}, used only in
Numerical observation~\ref{obs:family}, is listed separately in \nolinkurl{README.md}.
